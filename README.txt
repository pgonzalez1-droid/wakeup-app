WAKEUP - PROTOTIPO WEB V2

Sube el contenido de esta carpeta a la raíz del repositorio GitHub Pages, sustituyendo los archivos anteriores:
- index.html
- manifest.webmanifest
- sw.js
- icon.png

La URL publicada se mantiene. En iPhone, abre la web en Safari y usa Compartir > Añadir a pantalla de inicio. Si la icono antigua sigue apareciendo, elimina el acceso directo antiguo y vuelve a añadirlo.

Incluye navegación por pantallas, configuración independiente por reto, opciones y dificultad, lista de objetos, tonos generados y previsualizables, alarmas editables y selección de retos reflejada en Inicio.

LIMITACIÓN IMPORTANTE: iOS no garantiza que una PWA reproduzca alarmas con Safari cerrado o el iPhone bloqueado. Esta versión comprueba las alarmas mientras la página está abierta. Tampoco inicia Spotify automáticamente. La cámara/IA para verificar objetos o ejercicios todavía no está implementada.
